# 经历工作台 · Experience Workbench

**中文** | [English](README.en.md)

把你的**竞赛、项目、论文、专利、奖项、学生工作、实习、志愿服务、证书、交换经历**收进一个本地工作台：
节点倒计时提醒、材料归档、复盘笔记、一键导出 A4 简历。

> 一个零依赖的本地小服务 + 零构建前端。数据全部存在你自己的硬盘上，不联网、不上传、不需要账号。

![概览](docs/screenshots/01-overview.png)

---

## 为什么做这个

大学四年会攒下十几条「值得一提」的经历，但真到写简历、填保研材料、申请交换的时候，你会发现：

- 报名截止日期散在微信、邮件、QQ 群里，总是靠记忆；
- 获奖证书、作品截图、证明材料散在几个文件夹里，找一次翻半天；
- 每写一次简历就要重新回忆一遍「当时做了什么、拿到了什么名次」；
- 想复盘「这次比赛为什么没进决赛」，却没有地方记。

这个工具把上面四件事收在一处：**经历是唯一的主线**，节点（报名/提交/结果）、材料、复盘都挂在经历下面。

## 功能

### 经历档案
10 种内置类型，每种有自己专属的字段——竞赛记级别/赛道/名次/角色，论文记期刊/作者次序/收录情况，专利用申请号/授权公告日……切换类型时表单字段跟着变，不会问你不相关的问题。类型还能自己增删。

![经历档案](docs/screenshots/02-archive.png)

三种视图：看板（按阶段分组）、表格、时间线。点开任意一条进入侧栏详情，改完即存。

![经历详情](docs/screenshots/04-detail.png)

### 赛程节点与提醒
每条经历下面可以挂若干节点：报名截止 → 作品提交 → 结果公布，各带提前量（默认 30/7/3/1 天，可调）。服务每天在你设定的时刻（默认 08:00）扫一遍，到点弹系统桌面通知；**开机时会把错过的提醒补发一次**，不会因为关机漏掉。同一条提醒只发一次。

桌面通知走 Windows 原生 Toast（仅 Windows 生效）；macOS / Linux 上可以把提醒渠道切成邮件，或用 `data/outbox/` 里落盘的邮件内容自行处理。

### 材料库
证书照片、参赛作品、PDF 证明统一归档到 `data/attachments/`，在网页里直接预览（图片/PDF），Word 文档给下载链接。

![材料库](docs/screenshots/07-materials.png)

### 复盘笔记
赛后趁热写一段：做对了什么、卡在哪、下次怎么改。概览页会把最近的复盘翻出来摆在你面前。

![复盘笔记](docs/screenshots/08-retro.png)

### 简历导出
选口径（保研 / 求职 / 出国）× 语言（中文 / 英文）× 版式 × 格式（PDF / Word / 网页 / Markdown），右边实时看到 A4 纸张效果，自动分页、自动加页码、跨页章节自动标「（续）」。
单栏版式是逐条精确拆页的，屏幕所见即打印所得；**双栏 / 侧栏版式整页是一个 flex 容器，拆开会破版，那两种版式不做屏幕分页**，真实页数交给打印兜底。

- 9 种版式：经典单栏、极简留白、学术履历、典雅衬线、高密度、紧凑双栏、侧栏色块、清新双栏、顶部横幅。常用的三个可以收藏置顶，也可以上传自己的 HTML 模板；
- 内容超出一页时，屏幕上会提示「纸下面还有 N 处没填完」，只进屏幕预览、绝不印到纸上；
- 出国口径锁定英文稿；英文稿里没翻译的内容会在纸上标黄，并列出待翻译清单——刻意印出来，逼自己翻完；
- 支持证件照，位置随版式自动适配（单栏右上角、双栏侧栏顶部、色带右端）。

![简历导出](docs/screenshots/06-export.png)

### 竞赛库
内置 197 项赛事，覆盖大学生数学建模、蓝桥杯、互联网+、ICPC、电赛等：其中 164 项带级别认定（国家级 137 / 国际级 27），每项带主办方、届次节奏、适合的赛道；可按专业方向筛，一键「加入我的档案」自动套好赛程。剩下 33 项只收录基本信息，不猜级别。

同时内置教育部 816 个本科专业目录，搜索框支持分级匹配。

![竞赛库](docs/screenshots/05-library.png)

### 概览
在研竞赛数、7 天内到期的节点、待补材料、已获奖项，以及最近复盘和成果成就度。

![日程节点](docs/screenshots/03-schedule.png)

### 设置
提醒时刻与提前量、提醒渠道（桌面 / 邮件）、经历类型的增删，都在这里；改完即存。

![设置](docs/screenshots/09-settings.png)

## 快速开始

**要求：Node.js ≥ 18**（不需要 `npm install`，核心功能零第三方依赖）

Windows：双击 `start.bat`

macOS / Linux：

```bash
node server.js
```

然后浏览器打开 <http://127.0.0.1:8777>。端口被占用会自动往后找一个（8778、8779…），启动时控制台会打印实际地址。

首次启动会在项目下自动创建 `data/` 目录并写入空数据，直接开箱可用。

## 数据与隐私

- **全部数据都在本机**：`data/*.json` + `data/attachments/`。没有账号系统、没有埋点、不做任何统计上报。
- **默认不联网**：唯一的对外通道是「邮件提醒」，而且是**你自己可选开启**的——不填 SMTP 就完全不发，填了也只连你指定的那台邮件服务器。桌面通知走本机系统通道。邮件发送依赖可选的 `nodemailer`（装了才发；没装时提醒内容落盘到 `data/outbox/`，照样不丢）。
- **仓库里不含任何个人数据**：`data/`、`data/attachments/`、`qa/out/`、`*.log` 已全部写进 `.gitignore`。
- 写入即落盘，并在 `data/backups/` 保留一份滚动备份（只留最新一版），误删可回滚。
- README 里的截图使用**虚构人物数据**（林一鸣 / 云澜大学），与任何真实个人无关。

## 竞赛库数据来源

竞赛条目整理自公开渠道：中国高等教育学会《全国普通高校大学生竞赛分析报告》榜单，以及一份高校内部的竞赛认定名单。条目里的主办方、届次节奏为公开信息整理；**未认定/信息不足的条目刻意留空简介，不做猜测**。

教育部专业目录（`src/seed/majors.json`）来自教育部公开文件。

竞赛库仅作为备赛参考，赛事的具体报名时间、赛制、奖项认定请**以主办方官方通知和你所在学校的认定文件为准**。

## 自检

`qa/` 下是两套端到端自检，用 CDP 驱动真实的 Edge，零第三方依赖：

```bash
node qa/check-func.js    # 155 项：增删改查、导出排版、提醒、材料、照片落位
node qa/check-resp.js    # 121 项：6 个宽度 × 8 个视图的响应式布局
```

在当前代码上，**刚 clone 下来、库还是空的时候**跑，结果是 **155 / 155、121 / 121，0 条控制台报错**。

脚本会自己备齐数据夹具（载入示例经历、补一份虚构个人资料、现场生成一张 1×1 的证件照、挂上三种格式的材料），
且**只填空缺、不覆盖已有数据**；前置条件在当前数据集里不成立时记 `SKIP` 并说明原因，不算失败。

断言涵盖几何尺寸（不写死像素，量相对关系）、真实点击、导出纸张像素等。跑之前建议先把项目复制一份沙箱目录再启动，避免污染真实数据——具体做法和已知问题见 `qa/README.md`。

## 开发约定

- **零依赖、零构建**：没有 `node_modules`，没有打包步骤，改完刷新页面就生效。前端不引入框架，状态放一个 `S` 对象。
- **单一真源**：经历类型与专属字段只定义在 `src/taxonomy.js`，前端通过 `/api/state` 读取，服务端与前端不会各自维护一份。
- README 截图由 CDP 驱动真实浏览器从**虚构数据集**上实拍，不是手绘稿。
