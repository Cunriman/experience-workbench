# tools/ 竞赛库来源与合并

内置竞赛库（`src/seed/competitions.json`）由两份东西拼起来：

| 来源 | 提供什么 | 落在哪 |
|---|---|---|
| 中国高等教育学会《全国普通高校大学生竞赛分析报告》榜单（84 项） | 赛事骨架：名称、主办方、类别、官网、大致时间窗口、赛程模板 | 条目的 `tier` / `organizer` / `site` / `window` / `stages` |
| 某高校《本科生学业竞赛项目库（2024 年修订）》 | **校内认定档次**（四档）+ 榜单里没有的 105 项赛事 | 条目的 `recognition` |

校内档次是保研/评奖时真正被拿来定的口径，所以它和学会榜单是**两个并列的口径**，
界面上也分开显示，不混成一条。

> ⚠️ 认定档次来自**特定一所学校**的名单。你在自己学校用，应替换为母校自己的认定表
> （流程见下面「重新生成」）。

## 文件

- `uni-list-2024.json` —— 从 PDF 抽出的 165 条清单（`no` 是全篇连续序号，映射表按它写）
- `parse-pdf-text.js` —— PDF 纯文本 → 上面这个 JSON
- `extract-pdf.py` —— PDF → 纯文本（依赖 `pypdf`，不进项目依赖）
- `merge-uni-list.js` —— 把清单并入 `src/seed/competitions.json`

并入前的骨架快照（`baseline-before-*.json`）属于**本地工作副本**，仓库里不带；
需要回滚时自己重新导出 `src/seed/competitions.json` 留档即可。

## 重新生成（比如母校出了 2026 修订版）

```bash
# 1. PDF → 纯文本（pypdf 装在任意 venv 里即可）
python tools/extract-pdf.py "D:/下载/本科生学业竞赛项目库（2026年修订）.pdf" > pdf-out.txt

# 2. 纯文本 → 结构化清单
node tools/parse-pdf-text.js pdf-out.txt tools/uni-list-2026.json

# 3. 核对 parse 输出：四档各多少条，必须和 PDF 里的表对得上
#    （2024 版是 10 / 17 / 63 / 75，合计 165）

# 4. 人工核对映射表（见下），然后并入
node tools/merge-uni-list.js tools/uni-list-2026.json
```

`merge-uni-list.js` 是**幂等**的：重复跑结果一致，所以直接改 `src/seed/competitions.json` 是安全的。

并入完记得重启服务，然后在「设置 → 竞赛库」点一次**重置为内置骨架** ——
服务端只在 `data/library.json` 缺失时读骨架，否则不会自动跟着变。

## 为什么映射表是手写的

第一版想省事，写了自动模糊匹配。结果是错的：

- 「**美国**大学生数学建模竞赛」被判成了「**全国**大学生数学建模竞赛」（美赛≠国赛，两条不同的赛事）
- 「月球基地2050国际创新大赛」被并进了「中国国际大学生创新大赛」
- 「全国大学生化学实验竞赛」撞上了「全国大学生化学实验创新设计大赛」

原因是归一化时把「全国 / 大学生 / 竞赛 / 大赛」这些词都抹掉了，剩下的词干没有区分度。
所以现在：

1. 能对上的 **59 条**，写死在 `MERGE` 表里，每条都单独看过；
2. **拿不准的一律新增，不合并** —— 错并会丢掉一条真实赛事，新增最多只是库里多一条；
3. 归类规则按「具体优先」排序，把「设计 / 创意 / 创新」这类贪心词放最后
   （否则「飞行器设计大赛」「生物分子设计大赛」全会被判成艺术设计）。

已知没合并、留作新增的几对（名字像但不是同一条，或没法确认）：

| 清单里的 | 库里已有的 | 为什么不并 |
|---|---|---|
| RoboCom 机器人开发者大赛 | 睿抗机器人开发者大赛（RAICOM） | 无法确认是不是同一赛事的改名 |
| 「工商银行杯」全国大学生金融创意设计大赛 | 「工行杯」全国大学生金融科技创新大赛 | 同上 |
| 全国高校 BIM 毕业设计创新大赛 | 国际高校 BIM 毕业设计创新大赛 | 「全国 / 国际」是否同一赛事存疑 |
| 全国大学生海洋知识竞赛 | —— | 新增，归为测绘地理，可能更该算综合 |

## 已知的源文档瑕疵

`uni-list-2024.json` 第 117 条是「**0I**中国水下机器人比赛」。这是从 PDF 文字层原样抽出来的，
原文里那个字符是数字 `0` 还是字母 `O` 无法从文字层判断。为了忠实于源文档，**没有改**。
如果确认是 `OI`，直接改这个 JSON 再重跑 `merge-uni-list.js`。
